# Third-party components

This repository is Apache-2.0 (see `LICENSE`). The components below come from
elsewhere, keep their own licences, and have their original headers left intact.

## In-tree

| Path | Component | Origin | Licence |
|---|---|---|---|
| `common/vivado.mk` | Vivado FPGA Makefile | Alex Forencich | MIT — header retained, `Copyright (c) 2016 Alex Forencich` |
| `designs/03_qsfp_ibert/src/example_ibert_ultrascale_gty_0.v` | IBERT UltraScale GTY example design | Generated by Vivado | Xilinx/AMD — generated output, regenerable from the IP |
| `designs/03_qsfp_ibert/xdc/*.xdc` | IBERT example constraints | Generated by Vivado | Xilinx/AMD — generated output |
| `designs/03_qsfp_ibert/ip/ibert_ultrascale_gty_0.xci` | IBERT IP configuration | Generated by Vivado | Xilinx/AMD — generated output |

Vivado-generated files are the tool's output for a given IP configuration and are
reproducible by anyone with the same IP and parameters. They are checked in for
convenience and because the IBERT example carries hand-made fixes documented in that
design's README.

## Submodules (`third_party/`)

Fetched, not vendored. Each keeps its own licence.

| Submodule | Upstream | Licence |
|---|---|---|
| `dma_ip_drivers` | [Xilinx/dma_ip_drivers](https://github.com/Xilinx/dma_ip_drivers) | see its own `LICENSE` |

Additional dependencies are added as the designs that need them land. Anything derived
from Alex Forencich's `verilog-ethernet` / `verilog-pcie` family is MIT and will be
pulled as a submodule rather than copied, so upstream history and licence stay intact.
